RICHA SHARMA PORTFOLIO — QUICK START

1. Extract this folder.
2. Open the RichaPortfolio folder in VS Code.
3. Keep index.html, style.css, script.js, richa-avatar.png and resume.pdf together.
4. Open index.html in your browser, or use the VS Code Live Server extension.
5. The Download Resume buttons download resume.pdf.

Customize:
- Update text and links in index.html.
- Change colors and layout in style.css.
- Change interactions in script.js.
- Replace richa-avatar.png with your preferred portrait/cartoon, keeping the same filename.

Note: Project buttons currently link to your GitHub profile. Replace them with individual project repository links when available.
